# 象棋陪練（Windows 本機第一版）

這是一個在本機瀏覽器使用的象棋學習程式。你可以選「大師帶走」，每回合先看對手這一步的用意，再看我方建議與後續推演；也可以選「自主練習」，自己先走，明顯失誤時再看分層提示。對局、答題、錯題與練習結果保存在本機 SQLite。

## 開始使用

需要 Windows、Python 3.10 以上，以及已安裝的 Flask。於本目錄執行：

```powershell
python -m pip install -r requirements.txt
python -m chess_coach
```

也可以雙擊 `start_coach.bat`。程式會開啟 `http://127.0.0.1:5111/`；若瀏覽器未自動開啟，手動輸入該網址即可。結束時關閉命令視窗或按 `Ctrl+C`。

第一次啟動會建立 `instance/chess_coach.db`。這個檔案保存你的對局和錯題；備份時複製它即可。

## 操作順序

1. 在首頁選紅方或黑方、難度，以及「大師帶走」或「自主練習」。已有對局也能在對局頁切換模式。
2. 大師帶走時，電腦走完會先問「電腦這步想做什麼？」。猜它在將軍、吃子／捉子，還是調整位置；答完會顯示原因並在棋盤標示相關位置。按「看我方下一步建議」才顯示我方推薦走法；也能直接走棋跳過題目。
3. 大師帶走每回合在落子前標出建議走法，分開說明眼前問題與這步的作用。紅線標示直線將軍的攻擊路線。按「播放後續推演」可在獨立棋盤前後查看約兩到三回合的可能變化。
4. 想比較自己的想法時，按「比較我想走的棋」，在真實棋盤點選另一個合法走法。程式會顯示推薦走法與你的走法兩條分支，並指出對方可能的回應；比較及推演都不會改動真實局面。
5. 要真正落子時，點選棋子與合法落點。電腦會走下一步。被將軍時，棋盤會圈出能應將的棋子。
6. 如果走法有明顯損失，按「再給我一點提示」逐層查看；然後重走，或保留這步繼續。
7. 到「對局紀錄」逐步複盤，到「我的錯題」重練失誤局面；「學習概況」顯示累計結果。

目前的中文說明聚焦可在棋盤核對的直接吃子、將軍、應將與炮架變化。對手意圖題依走法可直接驗證的效果分類；「捉子」只表示若不處理，剛移動的棋子下一回合有可能吃子，並非預測對手必然這樣走。沒有能直接確認的戰術原因時，畫面會明說這只是引擎目前深度的偏好，再用兩條分支幫你比較。推演是引擎的一條可能路線，不代表對手必然照著走。三個對手難度對應不同搜尋深度；教練的分析深度可另行設定。

## 專案位置

- `CHESS_COACH_V1_PLAN.md`：第一版功能、設計、開發步驟及驗收點。
- `chess_coach/`：Flask 網站、棋規、UCCI 引擎通訊、SQLite 與網頁。
- `chess_coach/engines/`：本機使用的 ElephantEye 3.21 Windows 引擎及必要檔案。
- `tests/`：棋規、API、真實引擎及資料保存測試。
- `references/`：原 VB6 專案副本、UCCI 文件、引擎原始碼與研究資料。
- `build/eleeye-linux/eleeye`：已交叉編譯的 Linux 引擎；尚未在 Linux 執行驗證。

## 開發與設定

```powershell
python -m unittest discover -s tests -v
```

可透過環境變數設定 `CHESS_COACH_DATABASE`（SQLite 路徑）、`CHESS_COACH_ENGINE`（UCCI 執行檔）、`CHESS_COACH_ENGINE_TIMEOUT`（秒）、`CHESS_COACH_COACH_DEPTH`（失誤分析深度）與 `CHESS_COACH_GUIDE_DEPTH`（大師推演深度，預設 6）。`CHESS_COACH_OPEN_BROWSER=0` 可只啟動伺服器。重新啟動程式時，既有資料庫會自動補上教學模式欄位與對手意圖答題紀錄表，原有對局保留。

本機入口是 `python -m chess_coach`；WSGI 可匯入 `from chess_coach import app`。PythonAnywhere 部署前仍需在 Linux 實測引擎、確認執行額度與加入登入保護。第一版尚未處理長將、長捉等競賽細則。
